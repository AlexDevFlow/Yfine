Tags

Tags are colored labels you attach to movements and savings. Use them to group entries by category (groceries, transport, subscriptions, gifts) and then filter lists by tag.

What you see
  • A form at the top to add a new tag: name input, color picker, and emoji picker.
  • A table of existing tags. Each row shows the tag as it will appear, a usage count badge (movements + savings), and per-row actions.
  • Clicking a tag row opens the movements page filtered by that tag.
Per-row actions
Edit Switch the row to edit mode. Change the name, color, or emoji.
Save Appears only in edit mode. Commits the changes to the tag.
Delete Remove the tag. Attached movements and savings keep their other tags.
Color and emoji

The color picker has a palette of presets and a custom hex input. The emoji picker is grouped by category (people, food, activities, objects) with a search box.

Examples:

  • 🛒 groceries
  • 🚗 transport
  • 📺 subscriptions
  • 🎉 gifts
Step by step: create a tag
  1. Type the name in the input at the top of the page.
  2. Click the color swatch and pick a color, or enter a hex value.
  3. Click the emoji icon and pick one (optional).
  4. Click Add Tag. The tag appears in the table.
Step by step: rename or recolor
  1. Click Edit on the row.
  2. Change the name, color, or emoji.
  3. Click Save.
Click any tag in the table (outside edit mode) to jump straight to movements filtered by that tag. Useful for quick category reviews.
Deleting a tag removes it from every movement and saving that used it. The movements themselves are not deleted.
